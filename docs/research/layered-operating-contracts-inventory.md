## 5. Harness instruction-loading semantics

All sources were accessed on 2026-10-19.

The installed versions were checked locally: Claude Code 2.1.303, OpenCode
1.19.0 and Codex 0.160.0. The OpenCode findings come from source at tag
v1.19.3, which is newer than the installed version, and they contradict the
OpenCode docs on one point. They need a fixture test before anyone relies on
them (see section 7).

### Claude Code

Primary source: <https://code.claude.com/docs/en/memory>.

- **Files.** These load: managed `CLAUDE.md`, `~/.claude/CLAUDE.md`,
  `./CLAUDE.md` or `./.claude/CLAUDE.md`, `./CLAUDE.local.md`, and
  `.claude/rules/**/*.md`. A rule with `paths:` frontmatter loads only when a
  matching file is used.
- **Walk.** The working directory and every directory above it load, ordered
  from the filesystem root down. There is no stop at the git root. The files
  are concatenated and none overrides another.
- **Lazy loading.** A subdirectory's `CLAUDE.md` loads when a file in that
  subdirectory is read, written or edited.
- **AGENTS.md.** Native since v2.1.277. In the default mode
  (`claude-md-or-agents-md`), `AGENTS.md` and `.claude/AGENTS.md` load only
  when no `CLAUDE.md`, `.claude/CLAUDE.md` or `CLAUDE.local.md` exists in the
  working directory or above it. `~/.claude/CLAUDE.md` does not count for that
  check. The other modes are `claude-md-and-agents-md`, `claude-md` and
  `managed-only`, and they can be set only in user, `--settings` or managed
  settings.
- **Imports.** `@path` imports work up to four hops deep. Imports do not reduce
  context cost.
- **Exclusion.** `claudeMdExcludes` takes absolute-path globs and merges across
  settings layers. `--setting-sources` can drop the project or local layer.
- **Comments.** Block-level HTML comments are stripped before injection, so they
  can carry provenance markers.
- **Injection.** `SessionStart` accepts stdout or
  `hookSpecificOutput.additionalContext`, capped at 10,000 characters per
  string. Over the cap the text is saved to a file and only a preview of up to
  2,000 characters is injected. Source:
  <https://code.claude.com/docs/en/hooks>.
- **Size.** Under 200 lines per file is advised. A file over 4 MiB is skipped.
  The warning thresholds are not stated (UNKNOWN).

### OpenCode

Sources: <https://opencode.ai/docs/rules>, <https://opencode.ai/docs/config>
and source at tag v1.19.3, `packages/opencode/src/session/instruction.ts`.

- **Docs.** Local `AGENTS.md`/`CLAUDE.md` are found by walking up the tree,
  then the global `~/.config/opencode/AGENTS.md`, then `~/.claude/CLAUDE.md`.
  "The first matching file wins in each category."
- **Source.** The project walk is `findUp(cwd → worktree)`.
  - The first filename in `[AGENTS.md, CLAUDE.md, CONTEXT.md]` that has any hit
    wins, and *every* hit of that name along the path loads, **nearest first**.
  - Outside git, the worktree is `/`.
  - The global file is the first of `~/.config/opencode/AGENTS.md` and
    `~/.claude/CLAUDE.md` that exists.
- **`instructions`.**
  - A relative path is globbed in the working directory and every ancestor up
    to the worktree.
  - For an absolute path, only the last path component is globbed.
  - `~/` is expanded.
  - A glob with no matches, an empty file and a failed URL are all ignored
    without notice.
  - `instructions` arrays concatenate across config layers with duplicates
    removed (`config.ts`).
- **Order.** Each file is emitted as `Instructions from: <path>`, in this
  order: global, project nearest first, `instructions` files, then URLs.
- **Read tool.** The Read tool also attaches any `AGENTS.md`/`CLAUDE.md` found
  by walking up from the file it reads (`tool/read.ts`).
- **Disabling the Claude fallback.** `OPENCODE_DISABLE_CLAUDE_CODE*` turns it
  off.
- **Injection and size.** The only documented injection hook is
  `experimental.session.compacting`; there is none at session start. No size
  limit is documented (UNKNOWN).

### Codex CLI

Sources: <https://learn.chatgpt.com/docs/agent-configuration/agents-md> and
source at tag rust-v0.163.0, `codex-rs/core/src/agents_md.rs`.

- **Global file.** `$CODEX_HOME/AGENTS.override.md` if present, otherwise
  `AGENTS.md`. Only the first non-empty one loads.
- **Project walk.**
  - It runs from the project root down to the working directory and takes at
    most one file per directory (override, then `AGENTS.md`, then fallback
    names).
  - The project root is the nearest ancestor containing a
    `project_root_markers` entry; the default is `[".git"]`. Codex **never
    reads above the root**.
  - An untrusted project loads no project files.
- **Order.** Root to working directory, joined by blank lines, so closer files
  come later.
- **Size.** `project_doc_max_bytes` defaults to 32,768 bytes. The file that
  crosses the budget is truncated and a warning is logged.
- **Injection.** `developer_instructions` is injected before `AGENTS.md`. A
  `SessionStart` hook's output becomes developer context;
  `additionalContextLimit` defaults to 2,500 tokens. Source:
  <https://learn.chatgpt.com/codex/hooks>.

### Comparison

| Harness | Walk boundary | Order | Exclusion | Session-start injection | Size limit |
|---|---|---|---|---|---|
| Claude Code | working directory up to the filesystem root; subdirectories lazy | root first | `claudeMdExcludes`, `--setting-sources`, AGENTS.md mode | `SessionStart` (10k characters per string) | files over 4 MiB skipped; 200 lines advised |
| OpenCode | working directory up to the git worktree (or `/`) | **nearest first** | `OPENCODE_DISABLE_CLAUDE_CODE*`; per-file exclusion UNKNOWN | none (compaction only) | UNKNOWN |
| Codex | project root (`.git`) down to the working directory; nothing above the root | root first | override file, fallback names | `SessionStart` (2,500 tokens); `developer_instructions` | 32 KiB (truncates) |

## 6. Prior art for per-type merge rules

All sources were accessed on 2026-10-19.

- **Nix module system.** Source: <https://nixos.org/manual/nixos/stable/>,
  manual version 26.05.
  - Ordinary definitions have priority 100 and option defaults 1500.
    `mkForce` is `mkOverride 50` and `mkDefault` is `mkOverride 1000`; only
    the definitions with the lowest number survive.
  - The merge depends on the option's type: `str` cannot be merged, `lines`
    joins with newlines, `listOf` concatenates and `attrsOf` joins.
  - A custom type supplies `merge loc defs`, and each definition carries the
    file it came from.
  - This is the closest analogue to merge rules that vary by kind of
    declaration, and to a manifest that records provenance.
- **EditorConfig (spec 0.17.2).** Source: <https://spec.editorconfig.org/>.
  - The search runs up from the file's directory and stops at `root = true` or
    at the filesystem root.
  - Closer files take precedence.
- **Git config (2.56.0).** Source: <https://git-scm.com/docs/git-config>.
  - The scopes are system, global, local, worktree and command; the last value
    read wins.
  - Keys with several values collect all of them.
  - `include.path` and `includeIf` insert content at the point of the include,
    resolving relative paths against the including file.

## 7. Implications for the design (derived; provisional until LOC.07)

- **Each layer emitting only its own delta (option A) works only in Claude
  Code.**
  - Codex never reads above the git root, so a layer in `~` or `~/spaces` is
    invisible to it except through `~/.codex/AGENTS.md`.
  - OpenCode stacks files nearest first, which reverses the
    "later instruction wins" order. Its `instructions` globs resolve per
    ancestor, not per config file.
- **A three-band hybrid fits all three harnesses.**
  1. Global band: the root layer `~/.ημ` folds into each harness's global file
     (`~/.claude/CLAUDE.md`, `~/.config/opencode/AGENTS.md`,
     `~/.codex/AGENTS.md`).
  2. Ancestor band: layers between `~` and a repository root (for example
     `~/spaces/.ημ`) fold into that repository's root projection, because
     Codex cannot see them otherwise.
  3. In-repository band: per-directory deltas, composed by the harness for
     Claude Code and Codex. OpenCode folds at the git root.
- **Cost of folding everything into one file per harness (option B).** It is
  deterministic, but it gives up the lazy subdirectory loading of Claude Code
  and OpenCode.
- **Budgets bind differently.**
  - Codex truncates project files at 32 KiB, so it needs a hard ceiling.
  - Claude Code's `SessionStart` injection is capped at 10k characters and
    Codex's at 2,500 tokens, so the tier-0 core alone fits injection.
- **Duplicate suppression.** On Claude Code, the AGENTS.md mode and
  `claudeMdExcludes` together can prevent the double load in `~`. That is a
  settings change, which muse could own as part of the projection.
- **Next experiment.** Before LOC.07 decides, build a fixture tree: marked
  files in `~`, at a git root and in a subdirectory. Record the actual load
  order in all three installed harnesses. This resolves the OpenCode
  docs-versus-source conflict.
