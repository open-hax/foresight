# Make the Alpha law kernel actually load

`alpha.law.artifact` shipped in PR #2 with an unbalanced bracket in the
`Condition` registry schema, so the namespace could not be read at all. Every
namespace that requires it — `alpha.law.markdown.profile`, `.facet`, and all
three test namespaces — was therefore unloadable too.

The PR #2 note is explicit that its execution container had no Clojure, NBB, or
Mermaid and that it did not claim the committed tests had run. PR #3 then
stacked markdown profiles and facets on top of a kernel that had never been
read, and the two later test commits added assertions to a suite that could not
execute.

## Acceptance

- `alpha.law.artifact` reads.
- `clojure -M:test` in `alpha/` runs the committed suites and reports real
  counts.
- A gate exists that would have caught this, rather than relying on a human
  running the suite by hand.

---
Repaired: removed one surplus `]` closing the `::condition` registry map in
`alpha/src/alpha/law/artifact.cljc`. `clojure -M:test` now runs
13 tests / 43 assertions, 0 failures, 0 errors.

The acceptance criterion about a gate is NOT met. Nothing in this repository
runs the Alpha suite automatically. That is carded separately as
c697c36a-2247-47f5-a7a6-8e64150e0deb, which is where the portability lane
belongs.
