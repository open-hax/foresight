# Derive the Mu kernel from the Calliope/Knoxx/Epiphany archaeology

Three projects independently built one face each of the same thing. Calliope's
media workbench already separates immutable renders from scoped multidimensional
ratings, fast disposition from deep inspection, and model *proposal* from human
*acceptance* — and `src/fork_tales/law/audio.cljc` is already a Malli μ registry.
Knoxx's translation review built the queue/compare/correct/accept loop. Epiphany
contributed epistemic status and promotion: observations, working
interpretations, promotion candidates, and unresolved questions stay distinct.

The archaeology pass then widened Mu past evaluation entirely: any subject
brought before any intelligence with selected context, an intent, affordances,
and durable contributions. `Judgment` becomes one kind of `Contribution`;
`Rubric` becomes one way of expressing `Intent`.

That widening is genuinely load-bearing and also genuinely unproven. Nothing has
been written.

## Acceptance

- The archaeology matrix exists as a document before any code: for each item in
  Calliope, Knoxx, and Epiphany, classify as KEEP AS SHAPE/LAW · PURIFY TO
  `.cljc` · UI IDEA ONLY · LEAVE BEHIND.
- The smallest `.cljc` kernel is derived from the intersection, not invented.
  The standing guess is around seven shapes.
- The kernel is not named after the translation-review lineage. `ReviewCase`,
  `Evaluator`, and `Judgment` as root nouns encode one specimen as the ontology.
- Mu knows *why* something is shown; Π decides *how*. Side-by-side, waveform,
  and diff are representations selected from artifact roles, and none of them
  appear in the kernel.
- The archaeology rule is honoured explicitly: copy laws aggressively if sound,
  copy pure functions after purification, copy persistence never. Knoxx's
  `domain/label/audio.cljs` owns JSON files, directory creation, and symlink
  projection from inside `domain` — the concept survives, that namespace does
  not.
