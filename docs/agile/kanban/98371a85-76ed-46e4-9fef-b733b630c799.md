`package.json` scripts. Define an explicit data-driven command map for
Clojure projects and multi-surface repositories such as Knoxx without
guessing aliases or recursively running every nested package.

- Missing tools and service-dependent suites remain explicit.
- Aggregate outcomes distinguish passed, failed, skipped, and unavailable.
