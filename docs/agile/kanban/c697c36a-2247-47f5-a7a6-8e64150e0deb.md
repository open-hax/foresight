# Make .cljc portability executable evidence rather than a filename claim

The root mandate says shapes, laws, and pure functions default to `.cljc` so
they are usable from any Clojure context. Right now nothing proves that. Two
independent instances of the same failure already exist:

- Alpha's laws were unreadable on every runtime for three commits
  (ba576807-35ff-4ccf-a627-5e31100fc1a0).
- Katamorph declares a `:test-jvm` alias whose `-m katamorph.jvm-test-runner`
  does not exist and whose `test/clj` path is absent, so the JVM lane that was
  supposed to be the portability evidence has never run. The `.cljc` suites do
  pass when invoked directly, which means the gap is the lane, not the code.

A file extension is a claim. A second runtime executing the same source is
evidence. Until a gate runs both, "portable" is decoration.

## Acceptance

- Alpha's law suites execute under JVM Clojure **and** under a second runtime
  reachable from this workspace (NBB or CLJS), from the same `.cljc` sources.
- Katamorph's portable schema suites execute on both sides, invoked by a lane
  that exists.
- `nbb scripts/workspace.clj` grows a way to run Clojure gates, or the gap is
  recorded explicitly — see 98371a85-76ed-46e4-9fef-b733b630c799.
- A deliberately broken portable source fails the gate. Verified by probe, not
  assumed.
- Unavailable runtimes are reported as unavailable, never as a pass.
