# CS1.05 — Evaluate Epiphany as a cognitive observatory, not archaeology only

## User story

**As a** human trying to understand an evolving agent system,  
**I want** Epiphany evaluated as the layer that observes, synthesizes, projects,
and explains knowledge/dynamics over provenance,  
**so that** archaeology remains one powerful mode without shrinking the product
to only archaeology.

## Acceptance criteria

- [ ] Archaeology remains a first-class Epiphany capability and source of evidence.
- [ ] Proposed broader responsibilities are separated from Clio's event authority, Truth's simulation kernel, Rheos work/document lifecycle, and agent-runtime execution.
- [ ] Epiphany projections retain references to exact source events and clearly mark observed, derived, provisional, accepted, and approximate state.
- [ ] At least one non-archaeology projection consumes the same underlying provenance without inventing a second source of truth.
- [ ] Current repository evidence controls what Epiphany actually owns today; future identity is recorded as a proposal until implemented and reviewed.

## Tasks within this story

- [ ] Recover current Epiphany contracts and the existing simulation-related notes.
- [ ] Draw the boundary between observation/synthesis/projection and execution/simulation/ledger authority.
- [ ] Feed the resulting inspection needs into CS1.07.

## Non-goals

Turning Epiphany into the ledger, simulation engine, board, or universal runtime.
