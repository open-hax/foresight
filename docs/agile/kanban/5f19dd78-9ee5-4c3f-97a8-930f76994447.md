# Inventory root consolidation inputs without granting execution authority

Foresight includes independently owned repositories from `.gitmodules` and
intentional root consolidation inputs. `.agents/` is the canonical skill
catalog and `eta/` is a root-owned Clojure harness. Compatibility originals
remain in place while the consolidated sources improve.

## Acceptance

- Inventory and reports contain 12 direct submodules plus `.agents` and `eta`.
- Every row states source type, ownership, and action eligibility.
- Metadata inspection stays at each declared root; nested packages, skills,
  symlinks, and Git repositories do not become workspace action targets.
- `--all` selects only action-eligible direct submodules.
- `--only .agents`, `--only eta`, and mixed actionable/non-actionable
  selections fail before spawning commands.
- Direct calls to action and jscpd execution reject inventory-only sources.
- Documentation explains consolidation without implying removal of originals.
