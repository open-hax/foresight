# Purify the eta-mu turn processor into a portable turn decision

Eta is transduction: a harness consumes an artifact and produces another, usually
through agents and tools. The eta-mu turn processor is the most valuable
surviving instance of that, and the decomposition it wants is clear:

```
turn input + conversation/session facts + tool/result facts + agent contract
                              ↓
                    PURE TURN DECISION          ← wants to be .cljc
                              ↓
   next model request · tool invocation intent · completion · continuation
                        · emitted facts
```

Everything ugly stays outside as adapters: OpenAI and Anthropic wire formats,
Node streams, HTTP, AbortController, Mongo/Redis, process lifecycle. Normalized
facts cross the boundary; native objects do not.

This is the card that gives Eta a real consumer of the Alpha kernel, and gives
Mu something real to judge.

## Acceptance

- The turn decision is a pure function of normalized facts, in `.cljc`, with no
  provider, transport, or process dependency reachable from it.
- Provider output is treated as untrusted input and validated at the edge — a
  law Knoxx paid for.
- At least two provider wire formats normalize into the same fact shape, which
  is the only thing that proves the boundary is real.
- The existing eta-mu behaviour is preserved; this is an extraction, not a
  redesign. Where behaviour must change, it is called out rather than absorbed.
- The TUI is not in scope. `eta/` stays a small JVM Clojure harness until it
  gets in the way.

## Boundary

eta-mu is an independently owned repository. `eta/` is root-owned. Where the
extracted kernel finally lives is part of this card's decision, but the work in
eta-mu is a PR there.

---
Note that the harness's own architecture rule already points this way:
`law.*` → `shape.*` → `extern.*` → `domain.*` → `infra.*`. The purification is
mostly a matter of making the existing construction order load-bearing across
runtimes rather than only within one.
