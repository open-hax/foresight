# Make Muse a portable evidence-aware agent control plane

Build the provider- and host-neutral contracts that let agents running through
Claude, OpenCode, Codex, MCP, and later remote workers share evidence and
lifecycle observations without giving Muse ownership of historical truth,
authority, or host-specific process semantics.

## Already delivered before board reconciliation

- Epiphany historical corpus search is exposed through Muse's MCP, OpenCode,
  and Claude projections as bounded, provenance-rich context packets.
- A host-neutral agent-event law and pure Codex app-server v2 translator cover
  session, turn, item, tool, approval/input wait, error, and completion events.

These are implemented foundations, not claims that freshness, live Codex
observation, authority, or cross-machine execution is complete.

## Dependency order

1. EvidenceRef v1 and authoritative freshness/resolution.
2. Cross-host event conformance corpus.
3. Passive Codex control-proxy observer with replay checkpoints.
4. Axxium authority and exactly-one approval owner.
5. Explicit headless Codex worker profile.
6. Cross-machine resolver and worker advertisement.

Each stage includes observability, append-only receipts, documentation,
migration compatibility, and focused verification gates.

## Done when

- Evidence references resolve through source-neutral contracts with explicit
  unavailable and stale states.
- Claude, OpenCode, and Codex event adapters pass one conformance corpus.
- Codex observation is passive and replay-safe before any authority is added.
- Exactly one component owns each approval response.
- Headless and cross-machine workers advertise explicit capabilities and
  authority requirements rather than relying on hidden host state.
