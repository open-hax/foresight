# Prove the Artifact/Event/Reaction kernel on three unlike documents

Rheos being "the Kanban thing" is a special case that hardened before the
general abstraction was visible. Epiphany's `document-governance.md` already
wrote the spec without meaning to: documents are first-class operational
artifacts that declare a `kind`, carry a `status`, an authority and an epistemic
tier, and relate to each other through `supports` / `informs` / `implements` /
`requires` / `reviews` / `verifies` / `accepts`.

Alpha now has most of the shapes — `Artifact`, `Relation`, `Event`, `Reaction`,
`Condition`, `MarkdownDocument`, and declarative Markdown profiles with facet
assertions. What is missing is the proof that they generalize.

## Acceptance

- Three genuinely unlike Markdown files pass through the same pure `.cljc`
  kernel: an Epiphany finding, a Calliope render review, and a Rheos story.
- Each retains its arbitrary frontmatter — preserved and queryable, not
  flattened into untyped mush and not forced into one universal schema.
- Each satisfies a different set of Katamorph facets, asserted per profile.
- Each emits the same generic `artifact/observed` and `artifact/changed` facts.
- Each can carry a completely different declarative reaction, matched by
  `Condition` against the artifact.
- The existing law holds: a reaction may only name a **registered** operation.
  No executable strings in frontmatter — `on-change: "bash deploy.sh"` must be
  impossible to express, not merely discouraged.
- Structural automation still refuses to make semantic judgments. Malformed
  frontmatter, missing fields, and broken relations are Alpha's call;
  "the sources do not justify this finding" is Mu's.
