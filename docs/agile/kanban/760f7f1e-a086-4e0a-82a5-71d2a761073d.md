# Complete the inflight portfolio and begin purified Knoxx extraction

Reconcile Foresight and every direct child repository to explicit terminal
states, then begin the next extraction wave without recreating Knoxx's bundled
translation/CMS/rendering architecture.

The governing program spec is
[`docs/specs/inflight-completion-and-knoxx-lift.md`](../../specs/inflight-completion-and-knoxx-lift.md).

## Acceptance

- Every PR in the opening portfolio is merged, superseded, split, rejected, or
  explicitly blocked with an owner and unblock proof.
- Translation generation plus SME review is a separate workstream from content
  generation, layout, publishing, and product/content review.
- Portable shapes and laws are purified before runtime adapters move.
- Revision-bound unit, integration, E2E, coverage, security, live-smoke, and
  independent-review evidence is required according to change class.
- Board events, Receipt River records, and Session Mycology learning remain
  durable and append-only.

## Boundary

Foresight coordinates independently owned repositories. This epic does not
grant the root authority to rewrite child package policy, secrets, deployment
state, or unaccepted domain semantics.
