Add root documentation and an NBB script that treats direct
`.gitmodules` entries as independently owned repositories.

## Acceptance

- `nbb scripts/workspace.clj inventory` reports every direct submodule,
  including `opencode`, its lockfiles, selected package manager, and root
  package scripts.
- `report` writes JSON and Markdown summaries under `reports/`.
- `install`, `build`, `test`, and `lint` require explicit `--only` or
  `--all`, use frozen installs, and run only exact root package scripts.
- Unsupported or ambiguous repositories are reported as skips and do
  not become false passes.
- Pure parser and package-manager decisions have NBB tests.
