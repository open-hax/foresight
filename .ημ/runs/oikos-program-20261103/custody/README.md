or syntax correction. An archived original is not a valid parsed review merely
because its bytes are preserved. Corrections do not create new independent
review approval, execution evidence, or board authority.

original local path. Its exact bytes are also preserved here as a text artifact;

delimiters. The original malformed `.edn` is excluded from the valid checkpoint
set, not deleted or silently treated as passing validation.
